Digidirect Quick View
=====================

[wiki link](https://wiki.digidirect.com/display/IPP/Quick+View)

### VERSION 1.0.0

The module allows the user on product list and search page to see product details by clicking on quick view button.

For add digidirect_quickview_* custom handle need to add action name to di.xml.

##### An admin is able to:
- enable/disable quick view.

##### User can see:
- quick view button on product list and search pages
- product details on product list and search page after clicking on quick view button
