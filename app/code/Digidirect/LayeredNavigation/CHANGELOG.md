1.0.0
=============
* Solution Architecture:
    * [#137810](https://digidirect.tpondemand.com/entity/137810) -- Layered Navigation. Solution Architecture
* New features:
    * [#142013](https://digidirect.tpondemand.com/entity/142013) -- GENERAL SETTINGS. As an admin, I want to be able to configure SLN module
    * [#160175](https://digidirect.tpondemand.com/entity/160175) -- MOBILE APPLY. As an admin, I want to be able to add "apply" button on mobile devices only (see description)
    * [#162071](https://digidirect.tpondemand.com/entity/162071) -- PRICE MULTI-SELECT. As an admin, I want to be able to enable multiple option selections for the price on the product listing page
    * [#161159](https://digidirect.tpondemand.com/entity/161159) -- NOFOLLOW/NOINDEX. As an admin, I want to be able to mark attribute as not indexable, not followed by search engines
    * [#142032](https://digidirect.tpondemand.com/entity/142032) -- ATTRIBUTE SETTING. As an admin, I want to have extra settings for product attribute
    * [#125976](https://digidirect.tpondemand.com/entity/125976) -- SEO. As a user I want SEO-friendly URLs to be generated automatically for the filters
    * [#125936](https://digidirect.tpondemand.com/entity/125936) -- LISTING PAGE. As a user, I want to be able to apply multiple options of one filter on the page
    * [#147115](https://digidirect.tpondemand.com/entity/147115) -- AJAX MODE/SORTING. As a user, I want to see products on the page without page reload (see description)
    * [#146609](https://digidirect.tpondemand.com/entity/146609) -- SAVE FILTERS. As a user, I want applied filters to be saved for the listing pages if I left the page and return with "Back" button
    * [#153216](https://digidirect.tpondemand.com/entity/153216) -- SHOW MORE ATTRIBUTE. As an admin, I want to be able to enable show more option for an attribute
    * [#153218](https://digidirect.tpondemand.com/entity/153218) -- SHOW MORE FRONTEND. As an admin, I want to see "Show more" option for an attribute on the layered navigation (see description)
