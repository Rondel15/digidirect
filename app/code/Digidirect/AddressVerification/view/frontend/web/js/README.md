## Autocomplete Settings

 Option | Type | Default | Description
 ------ | ---- | ------- | -----------
 mode | string | 'googleapi' | Autocomplete mode. 'googleapi' or 'post' available
 post | object | |  'post' mode options
 inputField | string | 'street[]' | name attribute of initializing field
 selectors | object |  | contain pairs "address_type": "field_name_attribute"
 config |object|  | contain pairs "address_type": "type_config"
 viewCustom | string | '' | path to custom View, used in component
