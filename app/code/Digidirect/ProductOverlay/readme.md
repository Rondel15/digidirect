## Digidirect Product Overlay extension

[wiki link](https://wiki.digidirect.com/display/LEGO/Overlays)

### Description.

The extension enables administrator to easily add bright labels to any store items and display them on product and category pages. Apart form that, the module automatically calculates and shows percent discounts or flat amounts based on the difference between special and regular price - just need to select the appropriate variable. You can also use one of 3 rounding algorithms to easily round discount amounts according to your specific needs.

Extensions creates new admin menu `Product Overlays` in `Digidirect` section.

#### Flexible conditions
With the conditions its possible to easily fine-tune badges display. Show product labels for Magento 2 based on:

* Product attributes;
* Attribute sets;
* Product category;
* Product SKU;
* New Product;
* On sale Product;

#### Set priorities for Magento 2 labels display
In case you have a number of labels or badges to show, you can easily specify the display priority. This handy feature will help you to avoid labels overlapping and show the ones with higher priority first.

#### Specify label position
Choose label position depending on the label's specifics. With the module you can show the badges or ribbons in the following positions: bottom-left, bottom-center, and bottom-right, middle-left, middle-center, middle-right, top-left, top-center, top-right.

#### Set time period to display labels
To effectively promote you products set particular date and time intervals for the badges to be displayed. The module will automatically stop displaying the labels as soon as the specified time period expires.

#### Show different labels to different customer groups
Flexible module settings allow you to specify to which particular customer group this or that product label will be displayed. It means that one label can be displayed to wholesalers only while another label will be visible to all customers.
