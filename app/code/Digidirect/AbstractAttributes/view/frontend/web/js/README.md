## Attribute Alphabetical Settings

Option | Type | Default | Description
------ | ---- | ------- | -----------
letterItems | jQuery object | $('[data-role="alphabetical-letter"]') | List of letters
letterContainers | jQuery object |  $('.alphabetical-section') | List containers of attribute options by each letter
letterHiddenList | jQuery object | $('.list.-hide') | Hidden lists  of attribute options in each container of letter
showMoreButton | jQuery object | $('[data-role="alphabetical-more"]') | Show more element of each letter container
scrollSpeed | integer | 500 | Speed of scroll to letter container
