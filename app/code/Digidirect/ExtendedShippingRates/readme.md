Digidirect Extended Shipping Rates
=====================

[wiki link](https://wiki.digidirect.com/display/LEGO/Extended+Shipping+Rates)

### VERSION 1.0.0

Extension allows admins to:
- flexibly configure shipping methods based on the business needs
 

##### An admin is able to:
- Specify shipping rules priority
- Add new shipping carriers
- Add new custom shipping methods
- Customize the default shipping methods settings
- Create flexible shipping rates depending on multiple conditions
- Specify shipping rules 
- Upload csv-file with shipping rates
##### User can:
- specify a shipping method which is appropriate for them
