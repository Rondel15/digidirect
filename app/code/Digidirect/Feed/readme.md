Digidirect Feed extension
=====================

[wiki link](https://wiki.digidirect.com/display/LEGO/Shopping+Feeds)

## Description.

Extensions creates new admin menu `Shopping Feeds` in `Digidirect` section.
New menu entries:

* Feeds
* Templates. We can create feed from template.
* Manage Filters. Used for filtering products for feed. We can assign multiple rules for feed.
* Dynamic Attributes. We can use dynamic attributes in feeds, used conditions like Magento_CatalogRule.
* Category Mappings. We can use category mappings in feeds.
* Reports.

There is a **"Library of patterns"** button near feed content area, where you can see, how to insert some values to feed.

Extension includes 50+ ready to use templates for all popular price comparison engines (Google Shopping, Amazon, eBay, Shopzilla, etc.).

*Before you create a new feed using template, you need to check product feed specification for the specified marketplace (template format type, fields delimiter, required fields, etc).*
