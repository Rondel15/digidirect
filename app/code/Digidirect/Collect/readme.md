# Digidirect Click & Collect

[wiki link](https://wiki.digidirect.com/pages/viewpage.action?pageId=21561933)

### Description
The extension creates new shipping method, manage goods quantity, stock status from physical stores, allows customers to pick up goods from physical store and refuse from delivery.

**Don't forget setup store country (Configuration -> General -> General -> Store Information -> Country)**


    The module needs Lego Base Theme version >= 1.0.5
